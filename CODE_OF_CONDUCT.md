# Code of Conduct

kb aims for a friendly, safe, and welcoming environment for everyone, regardless of experience level, gender identity and expression, sexual orientation, disability, personal appearance, body size, race, ethnicity, age, religion, nationality, or similar personal characteristics.

## Expected behavior

- Be kind. Rudeness is discouraged.
- Most technical decisions involve tradeoffs, not one clearly correct answer — engage with that in mind, rather than treating disagreement as someone being wrong.
- Keep criticism constructive. If something looks wrong, propose an alternative (or try it and report back) rather than criticism alone.
- Harassment of any kind is not tolerated, and results in exclusion from the project's spaces (issues, discussions, pull requests).
- Spamming, trolling, flaming, and attention-seeking behavior are not welcome.

## Reporting

If you experience or witness unacceptable behavior, please report it by opening a GitHub issue or contacting the maintainer directly. Reports will be handled with discretion.

## Scope

This applies to all project spaces — GitHub issues, pull requests, and discussions on this repository.
